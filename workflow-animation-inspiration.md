## Suggested Style for Your 6-Step Workflow
- **Pattern:** Sticky section + scroll progress + step-by-step reveal.
- **Visual:** Glassmorphism cards, soft gradients, depth shadows, and subtle 3D icon rotation.
- **Motion:**
  - Enter animations on each step (fade + translate + scale).
  - Progress line that fills as user scrolls.
  - Active step card enlarges while others dim.
  - Optional hover micro-interactions: tilt, glow, icon morph.
- **Mobile fallback:** Replace heavy 3D with lightweight Lottie/icon animations.
